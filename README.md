# ros-docker-scripts

The repo houses scripts scripts to run Robot Operating System (ROS) dockers.

This version supports ROS Lyrical on Ubuntu 26.04LTS.  Older versions are available on other branches.

1. The `docker` scripts are intended for text only dockers suitable for building, running and testing code.  Graphics do work but are not accelerated.
2. The `nvidia_docker` scripts do the same as that `docker` scripts and also allow the use of the NVidia GPU and its CUDA cores for simulation in `Gazebo` and `RViz2`.

Each version has a `README.md` file that explains how to use the scripts.
